# Lineage — where Gene comes from

Gene is the merged, evolved form of four ancestors. This file maps what
was taken from each — their special points, distilled into one organism.

## Gene-X — the cognitive spine
- Cognitive-architecture mindset: representation, cycles, agentic runtime
- Benchmarks as first-class citizens → Gene's evaluation-first evolution
- The conviction that intelligence is more than one model

## Gene-AI — the training discipline
- Training-infrastructure thinking: production pipelines, diagnostics,
  architecture audits → reborn as the trainer's strict task/checker
  separation and the progress reports committed every cycle
- Long-context ambitions → became episodic memory with replay

## gene-implementation — the wide experience
- The realization that scale without structure is noise (8,400 files of
  generated model debris) → the apoptosis law: prune what is not used
- Specializations and datasets → the curriculum-as-data principle
- Multimodal dreams → the sensory-interface boundary (words in, actions out)

## genesis — the soul
- Grounded learning: experience over corpus — the load-bearing idea
- Cognitive architecture docs (concepts, grounded responses, decisions)
- The developmental stance: walk before talk — curriculum maturation

## What was deliberately left behind
- Tokenizers and neural vocabulary machinery (no tokenizer in Gene)
- Gradient-descent training (no shifting weights)
- External model dependencies (fully in-house)
- Generated data junk (the repo stays clean; the mind is state, not debris)
